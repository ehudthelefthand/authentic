4-Layer Glow
Neon Effect

แนวคิดหลัก neon glow ที่ดูสวย ไม่ได้มาจากเส้นหนาเส้นเดียว
แต่มาจากวาด เส้นเดิม 4 ครั้ง บน ADD blend:

Outer  — weight×9,  alpha ต่ำมาก → halo
Mid    — weight×4.5, alpha กลาง → ขยายแสง
Inner  — weight×2.2, alpha สูง → ความเข้ม
Core   — weight×1,  alpha เต็ม → ความคม

ADD blend ทำให้แต่ละชั้นสะสม → ตรงกลางสว่างสุด
ใช้ปุ่มด้านล่างเพื่อ toggle แต่ละ layer
ดูว่า layer ไหนให้อะไร

ลอง toggle เหลือแค่ Core เพื่อดูความแตกต่าง
