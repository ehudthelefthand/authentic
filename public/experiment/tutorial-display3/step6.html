Flare
White-Hot Activation

แนวคิดหลัก เมื่อ arc เพิ่งถูก activate flareT = 0
แล้วค่อยๆ เพิ่มถึง 1 ตาม deltaTime / FLARE_MS

flare = 1 - flareT  ← 1 ตอนเพิ่งติด, 0 ตอน settle

จากนั้น lerp สีไปหาขาวตาม flare:
r = color.r + (255 - color.r) × flare
g = color.g + (255 - color.g) × flare
b = color.b + (255 - color.b) × flare

ผล: เพิ่งติด = ขาวจ้า → ค่อยๆ กลายเป็นสีจริง
คลิกบน arc เพื่อ trigger flare
คลิกหลายๆ ครั้งต่อกัน

ลองเปลี่ยน FLARE_MS ใน code:
400 = แฟลร์เร็ว, 3000 = fade ช้ามาก
ใน display-v3 บรรทัด 226–231: ใช้ Math.pow(flare, 0.5) เป็น ease curve ทำให้ flare drop เร็วตอนแรกแล้วช้าลง
