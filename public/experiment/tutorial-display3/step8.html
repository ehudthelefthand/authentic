สิ่งที่ display-v3 เพิ่มเติมจาก tutorial นี้
  • fingerprint.js — generate particle positions ให้เป็นรูปไอคอน camp จริงๆ แทนที่จะเป็นวงกลมเรียบๆ แต่ละ particle มี ring, angle, size, opacity, tangentAngle
  • Color transition — นอกจาก flare แล้ว ยังมี progress 0→1 ที่ lerp สีจาก transitionFrom → litColor ด้วย ease-out cubic 1 - (1-t)³ ทำให้ fade in นุ่มขึ้น
  • Stagger queue — pendingActivations[] + STAGGER_MS = 110ms ทำให้ arc ของ participant คนหนึ่งค่อยๆ ติดทีละอัน ไม่ได้ติดพร้อมกันหมด
  • Micro drift — dx = sin(t×0.55 + angle×2.1) × 0.008 ทำให้แต่ละ arc ลอยเล็กน้อย ไม่นิ่งสนิท
  • WebSocket real-time — connectWebSocket() รับ event จาก server แล้วเรียก enqueueParticipant() auto-reconnect ทุก 3s ถ้า disconnect
