Step 3 / 8 — Display-V3 Tutorial

Dark / Lit State
คลิกเพื่อติดแสง

แนวคิดหลัก แต่ละ arc มี state สองค่า:

null = dark (ยังไม่มีคนสแกน)
[r, g, b] = lit (มีคนสแกนแล้ว)

ตอน draw ตรวจ state แล้วเลือกว่าจะวาดด้วยสีมืดหรือสีสว่าง — ง่ายมาก แต่นี่คือ core ของ wall
Palette Index ใน display-v3 แต่ละ participant มี paletteIndex เป็น 0–7 ที่กำหนดสีของตัวเอง ตรงกับ getPalette() ใน fingerprint.js
คลิกบน canvas เพื่อติดแสง arc
กด R เพื่อ reset ทุกอัน

ลองดูว่าถ้า arc ทุกอันติดแสงหมด ดูต่างจากตอนไม่มีอะไรแค่ไหน
